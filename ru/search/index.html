Поиск по сайту

Поиск работает только на вашем устройстве: запрос никуда не отправляется, не попадает в адрес и историю браузера и стирается, когда вы уходите со страницы. Клавиатура телефона может запоминать набранные слова.

Поиск работает с включённым JavaScript. Ниже указатель всех страниц сайта по алфавиту.

Если это происходит сейчас

Не давайте объяснений без адвоката (ст. 51 Конституции). Что делать в первые минуты и куда писать, на странице «Срочно».

Если вам очень плохо прямо сейчас

Вы не одни. Позвоните по номеру 112, если есть угроза жизни. Бесплатные кризисные линии и психологи, которые работают с преследуемыми, на странице психологической помощи.

    Ничего не нашлось
